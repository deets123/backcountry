# Chat Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A chat box in the web app that turns requests like "make day 2 shorter" into a proposed settings change the user runs with one tap, and answers questions about a trip only from that trip's numbers, using a local model through Ollama.

**Architecture:** A new `src/backcountry/chat/` package: `facts.py` builds a plain-text fact sheet from a stored run; `models.py` talks to Ollama with the standard library behind a `ChatModel` interface; `proposal.py` holds the instructions, the JSON shape, and merges proposed changes through `GenerateRequest.from_dict`; `grounding.py` withholds replies with numbers, names or claims the facts don't support; `service.py` runs one chat turn; `eval.py` scores models on a test set. `POST /api/chat` exposes it; the web app adds a chat panel to Compare and Trip whose Run button calls the existing generate.

**Tech Stack:** Python 3.12, FastAPI, Typer, PyYAML (already dependencies), Python standard library `urllib` for Ollama; TypeScript web app (Vite, Vitest, Playwright). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-20-phase2-chat-design.md`

## Global Constraints

- No new dependencies (Ollama is called with `urllib.request`; `.env` is parsed by hand).
- Never commit API keys, secrets or `.env`. `.gitignore` already has `.env` and `evals/results/`; commit only `.env.example` (no values).
- The chat never produces geometry and never runs anything: a proposal only becomes a run when the user taps Run, which calls the existing `POST /api/regions/{id}/generate`.
- Replies follow CLAUDE.md: no invented water, campsites, permits, closures, trail conditions or trailhead access; never "safe"; miles and feet; no raw OSM ids (`osm:node/…`, `osm:way/…`) in anything the user reads, including the fact sheet.
- Ollama calls: `temperature: 0`, `stream: false`, `think: false`, `num_ctx: 8192` (the default 4,096 is too small), `format` = the JSON schema, 60 s timeout, one retry on invalid output.
- Default model `ollama:qwen3:14b` until the eval (Task 9) picks one; `OLLAMA_URL` default `http://127.0.0.1:11434`.
- User-facing wording for failures: unreachable → "The chat model isn't reachable (Ollama at 127.0.0.1:11434). Start Ollama, or plan with the form."; bad output → "The model's answer didn't make sense; try rephrasing."; withheld explanation → "I can't answer that from this trip's data."
- Plain styling in the web app; visual polish is a later, separate pass.

## Review Focus

1. A region with hundreds of trail names (Pemigewasset has 263) or a trip with many features: the fact sheet must stay within the model's context; names and features are capped. Test: Task 2 `test_fact_sheet_caps_long_lists`.
2. The model proposes impossible values (nights 0, daily [11, 6], a gain cap of −100, 5 camp pins for 2 nights): refused with the engine's own wording, no Run button. Test: Task 3 `test_impossible_values_are_refused_with_the_engines_reason`.
3. A reply that converts to other units ("10 km", "300 m") or quotes a number the facts don't have: withheld, not shown as fact. Test: Task 4 `test_other_units_and_unknown_numbers_are_withheld`.
4. Chat history containing a withheld (empty) assistant reply or junk roles: skipped, not sent to the model as an empty message. Test: Task 5 `test_history_skips_empty_and_unknown_messages`.
5. Ollama not running while the user chats: the panel shows the server's wording and everything else keeps working. Tests: Task 5 `test_chat_maps_model_errors_to_503_504_502`, Task 7 `shows the server's error and keeps the input usable`.

```python
SCHEMA = {"type": "object", "required": ["reply", "kind"], "additionalProperties": False,
          "properties": {"reply": {"type": "string"}, "kind": {"type": "string", "enum": ["change", "explain"]},
                         "span": {"type": "array", "items": {"type": "number"}, "minItems": 2, "maxItems": 2},

class _Resp(io.BytesIO):
    def __enter__(self):
        return self

    def __exit__(self, *exc):
        return False


def opener_returning(*contents, record=None):
    """An urlopen stand-in that answers each call with the next Ollama /api/chat body."""
    answers = list(contents)

    def open_(req, timeout):
        if record is not None:
            record.append({"url": req.full_url, "body": json.loads(req.data), "timeout": timeout})
        item = answers.pop(0)
        if isinstance(item, Exception):
            raise item
        return _Resp(json.dumps({"message": {"role": "assistant", "content": item}}).encode())
    return open_
```

```python
"""The chat model behind one small interface: a local model through Ollama now, Claude later.

Only the Python standard library is used (urllib), so the chat adds no dependency. Settings come from the
environment or a git-ignored `.env` at the repo root: BACKCOUNTRY_LLM=ollama:<model>, OLLAMA_URL.
"""

import json
import os
import socket
import urllib.error
import urllib.request
from pathlib import Path
from typing import Callable, Protocol

from backcountry.region import REPO_ROOT

DEFAULT_LLM = "ollama:qwen3:14b"
DEFAULT_OLLAMA_URL = "http://127.0.0.1:11434"
TIMEOUT_S = 60.0
NUM_CTX = 8192  # Ollama's default 4,096-token window is too small for a fact sheet plus a few messages


class ModelError(Exception):
    """A chat-model failure; the message is shown to the user as is."""


class ModelUnavailable(ModelError):
    pass


class ModelTimeout(ModelError):
    pass


class ModelBadOutput(ModelError):
    pass


class ChatModel(Protocol):
    name: str

    def complete(self, system: str, messages: list[dict], schema: dict, timeout_s: float = TIMEOUT_S) -> dict: ...


def _is(value, t: str) -> bool:
    if t == "number":
        return isinstance(value, (int, float)) and not isinstance(value, bool)
    if t == "integer":
        return isinstance(value, int) and not isinstance(value, bool)
    return isinstance(value, {"string": str, "object": dict, "array": list, "boolean": bool, "null": type(None)}[t])


def shape_problem(value, schema: dict, path: str = "answer") -> str | None:
    """The first way `value` breaks the (small) JSON schema, or None. Covers type, enum, required,
    additionalProperties, properties, items, minItems/maxItems: what the chat's answer shape uses."""
    if "type" in schema:
        types = schema["type"] if isinstance(schema["type"], list) else [schema["type"]]
        if not any(_is(value, t) for t in types):
            return f"{path} should be {' or '.join(types)}"
    if "enum" in schema and value not in schema["enum"]:
        return f"{path} should be one of {', '.join(str(v) for v in schema['enum'] if v is not None)}"
    if isinstance(value, dict):
        for key in schema.get("required", []):
            if key not in value:
                return f"{path}.{key} is missing"
        props = schema.get("properties", {})
        if schema.get("additionalProperties") is False:
            extra = [k for k in value if k not in props]
            if extra:
                return f"{path}.{extra[0]} is not allowed"
        for key, sub in props.items():
            if key in value and (problem := shape_problem(value[key], sub, f"{path}.{key}")):
                return problem
    if isinstance(value, list):
        lo, hi = schema.get("minItems"), schema.get("maxItems")
        if (lo is not None and len(value) < lo) or (hi is not None and len(value) > hi):
            return f"{path} should have {lo if lo == hi else f'{lo}-{hi}'} items"
        if "items" in schema:
            for i, item in enumerate(value):
                if problem := shape_problem(item, schema["items"], f"{path}[{i}]"):
                    return problem
    return None


class OllamaModel:
    def __init__(self, model: str, url: str = DEFAULT_OLLAMA_URL, opener: Callable = urllib.request.urlopen):
        self.model, self.url, self._open = model, url.rstrip("/"), opener
        self.name = f"ollama:{model}"

    def _post(self, payload: dict, timeout_s: float) -> dict:
        req = urllib.request.Request(f"{self.url}/api/chat", data=json.dumps(payload).encode(),
                                     headers={"content-type": "application/json"})
        where = self.url.split("//", 1)[-1]
        slow = ModelTimeout(f"The chat model ({self.name}) took longer than {timeout_s:.0f} s. Try again, or use a smaller model.")
        try:
            with self._open(req, timeout=timeout_s) as resp:
                return json.loads(resp.read().decode())
        except urllib.error.HTTPError as e:  # before URLError: HTTPError is a URLError
            if e.code == 404:
                raise ModelUnavailable(f"Ollama doesn't have the model {self.model}. Run `ollama pull {self.model}`, "
                                       "or pick another model in .env.") from e
            raise ModelBadOutput(f"Ollama answered {e.code}: {e.read().decode(errors='replace')[:200]}") from e
        except (TimeoutError, socket.timeout) as e:
            raise slow from e
        except urllib.error.URLError as e:
            if isinstance(e.reason, (TimeoutError, socket.timeout)):
                raise slow from e
            raise ModelUnavailable(f"The chat model isn't reachable (Ollama at {where}). Start Ollama, or plan with the form.") from e
        except json.JSONDecodeError as e:
            raise ModelBadOutput("Ollama sent something that isn't JSON.") from e

    def complete(self, system: str, messages: list[dict], schema: dict, timeout_s: float = TIMEOUT_S) -> dict:
        msgs = [{"role": "system", "content": system}, *messages]
        for _ in range(2):  # one retry, with the problem fed back
            out = self._post({"model": self.model, "messages": msgs, "format": schema, "stream": False, "think": False,
                              "options": {"temperature": 0, "num_ctx": NUM_CTX}}, timeout_s)
            text = (out.get("message") or {}).get("content", "")
            try:
                answer = json.loads(text)
                problem = shape_problem(answer, schema)
            except json.JSONDecodeError as e:
                answer, problem = None, f"it is not JSON ({e.msg})"
            if problem is None:
                return answer
            msgs = [*msgs, {"role": "assistant", "content": text},
                    {"role": "user", "content": f"That answer was invalid: {problem}. Reply again with only JSON in the required shape."}]
        raise ModelBadOutput("The model's answer didn't make sense; try rephrasing.")


class FakeModel:
    """Scripted answers for tests: each call returns the next item, or raises it if it is an exception."""

    def __init__(self, answers: list, name: str = "fake"):
        self.answers, self.name, self.calls = list(answers), name, []

    def complete(self, system: str, messages: list[dict], schema: dict, timeout_s: float = TIMEOUT_S) -> dict:
        self.calls.append({"system": system, "messages": messages, "schema": schema})
        if not self.answers:
            raise ModelBadOutput("The fake model has no more answers.")
        answer = self.answers.pop(0)
        if isinstance(answer, Exception):
            raise answer
        return answer


def read_env(path: Path = REPO_ROOT / ".env", environ: dict | None = None) -> dict:
    """KEY=VALUE lines from a .env file (blank lines and # comments ignored); the real environment wins."""
    environ = dict(os.environ) if environ is None else environ
    out = {}
    if path.exists():
        for line in path.read_text().splitlines():
            line = line.strip()
            if not line or line.startswith("#") or "=" not in line:
                continue
            key, value = line.split("=", 1)
            out[key.strip()] = value.strip().strip('"').strip("'")
    for key in ("BACKCOUNTRY_LLM", "OLLAMA_URL", *out):
        if key in environ:
            out[key] = environ[key]
    return out


def model_from_spec(spec: str, env: dict | None = None) -> ChatModel:
    provider, _, name = spec.partition(":")
    if provider == "ollama" and name:
        return OllamaModel(name, (env or {}).get("OLLAMA_URL") or DEFAULT_OLLAMA_URL)
    raise ValueError(f"Unknown chat model {spec!r}: use ollama:<model>, e.g. ollama:qwen3:14b (Claude support comes later).")


def model_from_env(env: dict | None = None) -> ChatModel:
    env = read_env() if env is None else env
    return model_from_spec(env.get("BACKCOUNTRY_LLM") or DEFAULT_LLM, env)
```

`src/backcountry/chat/facts.py`:
```python
"""The fact sheet: everything the chat model may know about the open trip, as short plain text.

Built only from a stored run (the engine's output) plus the region's trail and trailhead names. Miles and feet,
the app's "unknown" wording, and no raw OSM ids. The honesty check (grounding.py) compares replies against it.
"""

import re

from backcountry.export import kind_label
from backcountry.scoring import M_PER_MI

FT_PER_M = 3.28084
NEARBY_FT = 1640  # 500 m: split.py NEARBY_CAMP_M
MAX_FEATURES = 40
MAX_NAMES = 300
CAMP_KINDS = ("camp_site", "camp_pitch")


def mi(m) -> str:
    return "unknown" if m is None else f"{m / M_PER_MI:.2f} mi"


def ft(x) -> str:
    return "unknown" if x is None else f"{x:,.0f} ft"


def span(r) -> str:
    return "not set" if not r else f"{r[0]:g}-{r[1]:g} mi"


def start_name(trailhead: str, starts: list[dict]) -> str:
    for s in starts:
        if s["id"] == trailhead:
            return s["name"]
    if re.fullmatch(r"-?\d+(\.\d+)?,-?\d+(\.\d+)?", trailhead):
        return f"the map point {trailhead}"
    return "a start point from the trail data"


def _place(value: str) -> str:
    return "a point from the trail data" if value.isdigit() else value  # never a raw node id


def settings_text(req: dict, starts: list[dict]) -> str:
    gain = req.get("max_gain_day")
    parts = [
        f"start {start_name(str(req['trailhead']), starts)}",
        f"shape {req.get('type') or 'any'}",
        f"total {span(req.get('total'))}",
        f"nights {req['nights'] if req.get('nights') is not None else 'none (one day)'}",
        f"miles per day {span(req.get('daily'))}",
        f"gain cap {ft(gain) + ' per day' if gain is not None else 'none'}",
        "roads " + ("avoided" if req.get("no_roads") else "allowed"),
        "direction " + {"cw": "clockwise", "ccw": "counterclockwise"}.get(req.get("direction"), "either"),
        "must visit " + (", ".join(_place(v) for v in req.get("must_visit") or []) or "none"),
        "avoid " + (", ".join(_place(v) for v in req.get("avoid") or []) or "none"),
        "camps " + ("pinned at mile " + ", ".join(req["camps"]) if req.get("camps") else "placed by the engine"),
        "camps at known campsites only " + ("yes" if req.get("camps_at_sites") else "no"),
    ]
    return "Current settings: " + "; ".join(parts) + "."


def _trail_order(c: dict) -> str:
    out = []
    for s in c["segments"]:
        if not out or out[-1] != s["label"]:
            out.append(s["label"])
    return " > ".join(out)


def _title(kind: str, name: str | None) -> str:
    return kind_label(kind) + (f": {name}" if name else "")


def _status(kind: str) -> str:
    if kind in CAMP_KINDS:
        return "existence and status unknown"
    if kind.startswith("usfs"):
        return "status unknown"
    return "water presence unknown"


def _capped(items: list[str], cap: int) -> list[str]:
    return items[:cap] + ([f"(and {len(items) - cap} more)"] if len(items) > cap else [])


def fact_sheet(run: dict, n: int, trails: list[str], starts: list[dict]) -> str:
    c = run["candidates"][n - 1]
    lines = [settings_text(run["request"], starts), ""]
    lines.append(f"Route (candidate {n} of {len(run['candidates'])}, {c['kind']}): {mi(c['length_m'])}, "
                 f"gain {ft(c['gain_ft'])}, loss {ft(c['loss_ft'])}, road {mi(c['road_m'])}, walked twice {mi(c['repeated_m'])}.")
    lines.append(f"Trails in order: {_trail_order(c)}.")
    p = c.get("plan")
    if not p:
        lines.append("Days: not planned (no nights given).")
    else:
        for d in p["days"]:
            gain = f"gain {ft(d['gain_ft'])}, loss {ft(d['loss_ft'])}" if d["gain_ft"] is not None else "gain unknown, loss unknown"
            lines.append(f"Day {d['index']}: {d['start_label']} to {d['end_label']}, {mi(d['length_m'])}, {gain}.")
        for cp in p["camps"]:
            how = "pinned by you" if cp["pinned"] else "at a known campsite" if cp["site"] else "placed for mileage"
            near = (f"{len(cp['nearby'])} known campsite(s) within {NEARBY_FT:,} ft" if cp["nearby"]
                    else f"no known campsite within {NEARBY_FT:,} ft")
            w = cp.get("nearest_water")
            water = (f"nearest water: {_title(w['kind'], w['name'])}, {ft(w['distance_m'] * FT_PER_M)} away (presence unknown)"
                     if w else "nearest water: none listed")
            lines.append(f"Camp {cp['index']}: mile {cp['dist_m'] / M_PER_MI:.2f}, on {cp['on_name'] or 'an unnamed trail'}, "
                         f"{how}, location unverified; {near}; {water}.")
        lines += [f"Engine note: {x}" for x in p["notes"]]
        lines += [f"Constraint not met: {x}" for x in p["violations"]]
    lines += [f"Route note: {x}" for x in c["notes"]]
    feats = [f"- mile {f['dist_m'] / M_PER_MI:.2f}, day {f.get('day') or '-'}: {_title(f['kind'], f.get('name'))}, "
             f"{ft(f['off_m'] * FT_PER_M)} off the route ({_status(f['kind'])})" for f in c["features"]]
    lines.append("Campsites and water along the route (map features only):" if feats else "Campsites and water along the route: none listed.")
    lines += _capped(feats, MAX_FEATURES)
    lines.append("Candidates are ranked by penalty (lower is better): miles outside your ranges, road miles, miles walked "
                 "twice, and day-split problems.")
    lines += [f"Candidate {o['index']}: {o['kind']}, {mi(o['length_m'])}, gain {ft(o['gain_ft'])}, road {mi(o['road_m'])}, "
              f"penalty {o['penalty']:.2f}" for o in run["candidates"]]
    lines.append("Not checked by this tool: " + "; ".join(run["known_gaps"]) + ".")
    lines.append("Trail names in this region: " + "; ".join(_capped(sorted(set(trails)), MAX_NAMES)))
    lines.append("Trailheads you can start from: " + "; ".join(s["name"] for s in starts))
    return "\n".join(lines)
```

```python
"""What the model is told, the shape it must answer in, and how its proposed changes become settings.

Proposed changes are merged into the current settings and validated by the engine's own GenerateRequest, so the
chat can never ask for anything the form couldn't. The user sees the before/after lines and decides to run it.
"""

from difflib import get_close_matches

from backcountry.planning import GenerateRequest, RequestError

SYSTEM_PROMPT = """You help plan a backpacking trip in a trip-planning app. You can do two things:
1. Change the trip's settings when the user asks (kind "change"). Put only the settings that should change in
   "changes", using these fields: nights; total [low, high] miles; daily [low, high] miles per day; max_gain_day
   (feet per day, or null for no cap); type (loop, lollipop or any); no_roads (true or false); direction (cw, ccw
   or null); must_visit_add, must_visit_remove, avoid_add, avoid_remove (trail names exactly as listed in the
   FACTS); camps (the mile along the route where each night's camp should be, one per night, in order, or [] to
   let the app place them); camps_at_sites (true or false); trailhead (a trailhead name from the FACTS).
   The app shows the change to the user, who decides whether to run it. You never run anything, and you never
   draw or describe new routes. To make one day shorter or longer, move the camps: to shorten day 2, move camp 2
   to an earlier mile or camp 1 to a later mile.
2. Answer questions about this trip from the FACTS below only (kind "explain", changes {}).
If a request is unclear, ask one short question (kind "unclear", changes {}).
Rules:
- Use only numbers and names that appear in the FACTS, in miles and feet, rounded like the FACTS.
- Water, campsites, permits, closures, trail conditions, weather and trailhead access are not known to this app.
  Say they are unknown or not checked. Never say water is there or reliable, never say anything is open, legal or
  permitted, and never say a route is safe.
- Keep replies to two or three sentences.
Answer with JSON only: {"reply": "...", "kind": "change" | "explain" | "unclear", "changes": {...}}."""

_RANGE = {"type": "array", "items": {"type": "number"}, "minItems": 2, "maxItems": 2}
_NAMES = {"type": "array", "items": {"type": "string"}}
CHANGE_FIELDS = {
    "nights": {"type": "integer"},
    "total": _RANGE,
    "daily": _RANGE,
    "max_gain_day": {"type": ["number", "null"]},
    "type": {"type": "string", "enum": ["loop", "lollipop", "any"]},
    "no_roads": {"type": "boolean"},
    "direction": {"type": ["string", "null"], "enum": ["cw", "ccw", None]},
    "must_visit_add": _NAMES, "must_visit_remove": _NAMES, "avoid_add": _NAMES, "avoid_remove": _NAMES,
    "camps": {"type": "array", "items": {"type": "number"}},
    "camps_at_sites": {"type": "boolean"},
    "trailhead": {"type": "string"},
}
RESPONSE_SCHEMA = {
    "type": "object", "additionalProperties": False, "required": ["reply", "kind", "changes"],
    "properties": {
        "reply": {"type": "string"},
        "kind": {"type": "string", "enum": ["change", "explain", "unclear"]},
        "changes": {"type": "object", "additionalProperties": False, "properties": CHANGE_FIELDS},
    },
}

LABELS = {"trailhead": "Start", "type": "Shape", "total": "Total miles", "nights": "Nights", "daily": "Miles per day",
          "max_gain_day": "Gain cap per day", "no_roads": "Roads", "direction": "Direction", "must_visit": "Must visit",
          "avoid": "Avoid", "camps": "Camps", "camps_at_sites": "Camps at known sites only"}


class ProposalError(ValueError):
    """A proposed change that can't be used; the message says why, for the user."""


def _trail(name: str, trails: list[str]) -> str:
    by_lower = {t.lower(): t for t in trails}
    if name.lower() in by_lower:
        return by_lower[name.lower()]
    guess = get_close_matches(name, trails, n=1, cutoff=0.6)
    raise ProposalError(f"There's no trail named {name!r} in this region" + (f"; did you mean {guess[0]}?" if guess else "."))


def _trailhead(name: str, starts: list[dict]) -> str:
    for s in starts:
        if name.lower() in (s["id"].lower(), s["name"].lower()):
            return s["id"]
    raise ProposalError(f"No trailhead named {name!r}. Trailheads here: {', '.join(s['name'] for s in starts)}.")


def _edit(current: list[str], add: list[str], remove: list[str]) -> list[str]:
    out = [v for v in current if v.lower() not in {r.lower() for r in remove}]
    return out + [a for a in add if a.lower() not in {v.lower() for v in out}]


def apply_changes(request: dict, changes: dict, trails: list[str], starts: list[dict]) -> tuple[dict, list[str]]:
    new = {k: (list(v) if isinstance(v, list) else v) for k, v in request.items()}
    for key in ("nights", "total", "daily", "max_gain_day", "type", "no_roads", "direction", "camps_at_sites"):
        if key in changes:
            new[key] = changes[key]
    if new.get("max_gain_day") is not None and new["max_gain_day"] <= 0:
        raise ProposalError("That change doesn't work: the gain cap must be more than 0 ft (or none).")
    for field in ("must_visit", "avoid"):
        add = [_trail(n, trails) for n in changes.get(f"{field}_add", [])]
        remove = [_trail(n, trails) for n in changes.get(f"{field}_remove", [])]
        new[field] = _edit(new.get(field) or [], add, remove)
    if "trailhead" in changes:
        new["trailhead"] = _trailhead(changes["trailhead"], starts)
    nights = new.get("nights") or 0
    if "camps" in changes:
        miles = [float(m) for m in changes["camps"]]
        if len(miles) > nights:
            raise ProposalError(f"That change doesn't work: {len(miles)} camps for {nights} nights.")
        if any(b <= a for a, b in zip(miles, miles[1:])) or any(m <= 0 for m in miles):
            raise ProposalError("That change doesn't work: Camp miles must go up from one night to the next and be more than 0.")
        new["camps"] = [f"{m:g}" for m in miles]
    elif len(new.get("camps") or []) > nights:
        new["camps"] = []  # fewer nights than pins: let the engine place the camps again
    try:
        after = GenerateRequest.from_dict(new).to_dict()
        before = GenerateRequest.from_dict(request).to_dict()
    except RequestError as e:
        raise ProposalError(f"That change doesn't work: {e}") from e
    return after, describe_changes(before, after, starts)


def _show(key: str, v, starts: list[dict]) -> str:
    if key in ("total", "daily"):
        return "not set" if not v else f"{v[0]:g}-{v[1]:g} mi"
    if key == "max_gain_day":
        return "none" if v is None else f"{v:,.0f} ft"
    if key == "no_roads":
        return "avoided" if v else "allowed"
    if key == "direction":
        return {"cw": "clockwise", "ccw": "counterclockwise"}.get(v, "either")
    if key in ("must_visit", "avoid"):
        return ", ".join(v) or "none"
    if key == "camps":
        return "pinned at mile " + ", ".join(v) if v else "placed by the engine"
    if key == "camps_at_sites":
        return "yes" if v else "no"
    if key == "nights":
        return "none" if v is None else str(v)
    if key == "trailhead":
        return next((s["name"] for s in starts if s["id"] == v), "a start point from the trail data")
    return str(v)


def describe_changes(before: dict, after: dict, starts: list[dict]) -> list[str]:
    return [f"{label}: {_show(k, before.get(k), starts)} → {_show(k, after.get(k), starts)}"
            for k, label in LABELS.items() if before.get(k) != after.get(k)]
```

Note: the engine's own message for a bad `daily` is "daily must look like 18-26 (miles, low-high); got …" (from `planning.parse_range`), and for nights 0 "nights must be a whole number of at least 1"; the tests match those.

`src/backcountry/chat/grounding.py`:
```python
"""The honesty check on chat replies, before anyone sees them.

A reply is withheld when it uses a number the facts don't have (at the reply's own precision), names a trail or
place the facts don't mention, or makes a claim this app can't support (safe, water there, open, legal, permitted,
conditions). Saying such things are unknown or not checked is fine: a sentence with that wording is exempt.
"""

import re

CANT_ANSWER = "I can't answer that from this trip's data."

_NUMBER = re.compile(r"(?<![\w.])\d{1,3}(?:,\d{3})+(?:\.\d+)?|(?<![\w.,])\d+(?:\.\d+)?")
_BANNED = [
    (r"\bsafe(ly)?\b", "says something is safe"),
    (r"\bwater (is|will be|should be) (available|flowing|drinkable|reliable|there|present)\b", "says water is there"),
    (r"\breliable water\b|\bwater (source|supply) is reliable\b", "says water is reliable"),
    (r"\b(is|are) (open|closed)\b", "says something is open or closed"),
    (r"\blegal(ly)?\b", "says something is legal"),
    (r"\bpermitted\b|\bno permits? (is |are )?(needed|required)\b|\bdon'?t need a permit\b", "makes a permit claim"),
    (r"\bconditions (are|will be)\b|\b(trail|route|path) is (clear|passable|in good (shape|condition))\b", "describes conditions"),
]
_UNKNOWN = re.compile(r"\bunknown\b|\bnot (known|checked)\b|\bcan'?t (tell|say|know|check)\b|\bcannot\b|"
                      r"\bdon'?t know\b|\bisn'?t known\b|\bhasn'?t checked\b|\bno (data|way to)\b|\baren'?t checked\b")
_NAME = re.compile(r"\b((?:[A-Z][\w'’-]*\s){1,4}(?:Trail|Trailhead|Run|Road|Creek|Ridge|Knob|Mountain|Lake|Pond|Spring|Grade|Rocks|Plains))\b")


def _value(token: str) -> tuple[float, float]:
    """The number and half a unit in its last digit (6.3 → 0.05, 784 → 0.5)."""
    decimals = len(token.split(".")[1]) if "." in token else 0
    return float(token.replace(",", "")), 0.5 * 10 ** -decimals + 1e-9


def _numbers(text: str) -> list[str]:
    return _NUMBER.findall(text)


def check_reply(reply: str, facts: str) -> tuple[bool, list[str]]:
    reasons = []
    known = [float(t.replace(",", "")) for t in _numbers(facts)]
    for token in _numbers(reply):
        v, tol = _value(token)
        if not any(abs(v - k) <= tol for k in known):
            reasons.append(f"unsupported number '{token}'")
    for sentence in re.split(r"(?<=[.!?;:])\s+", reply):
        if _UNKNOWN.search(sentence.lower()):
            continue
        for pattern, why in _BANNED:
            if re.search(pattern, sentence, re.IGNORECASE):
                reasons.append(why)
    facts_lower = facts.lower()
    for name in _NAME.findall(reply):
        words = name.split()
        while len(words) > 1 and " ".join(words).lower() not in facts_lower:
            words = words[1:]  # "The Red Creek Trail" → "Red Creek Trail"
        if len(words) < 2:  # only the bare "Trail"/"Run" was left, and that word alone proves nothing
            reasons.append(f"names '{name}', which isn't in this trip's data")
    return (not reasons, reasons)
```

```python
"""One chat turn: facts in, a checked reply and (maybe) a validated proposal out. Nothing is run or saved."""

import json

from backcountry.chat.facts import fact_sheet
from backcountry.chat.grounding import CANT_ANSWER, check_reply
from backcountry.chat.models import ChatModel
from backcountry.chat.proposal import RESPONSE_SCHEMA, SYSTEM_PROMPT, ProposalError, apply_changes

HISTORY = 6  # earlier messages sent along with the new one


def trail_names(tg) -> list[str]:
    return sorted({d["name"] for *_, d in tg.graph.edges(data=True) if d.get("name")})


def start_names(region) -> list[dict]:
    return [{"id": th["id"], "name": th.get("name") or th["id"]} for th in region.trailheads]


def _history(history: list[dict]) -> list[dict]:
    kept = [{"role": h["role"], "content": str(h.get("text") or "").strip()} for h in history
            if isinstance(h, dict) and h.get("role") in ("user", "assistant")]
    return [m for m in kept if m["content"]][-HISTORY:]


def chat_turn(model: ChatModel, run: dict, n: int, message: str, history: list[dict], trails: list[str], starts: list[dict]) -> dict:
    facts = fact_sheet(run, n, trails, starts)
    answer = model.complete(f"{SYSTEM_PROMPT}\n\nFACTS\n{facts}", [*_history(history), {"role": "user", "content": message}],
                            RESPONSE_SCHEMA)
    kind, reply, changes = answer["kind"], answer["reply"].strip(), answer.get("changes") or {}
    proposal = note = None
    if kind == "change" and changes:
        try:
            request, lines = apply_changes(run["request"], changes, trails, starts)
            if lines:
                proposal = {"request": request, "changes": lines}
            else:
                note = "That wouldn't change any setting."
        except ProposalError as e:
            note = str(e)
    ok, reasons = check_reply(reply, f"{facts}\n{json.dumps(changes)}")  # numbers in the proposal may be quoted
    withheld = None
    if not ok:
        withheld = reasons[0]
        reply = "" if proposal else CANT_ANSWER
    return {"reply": reply, "kind": kind, "proposal": proposal, "note": note, "withheld": withheld, "model": model.name}
```

```python
"""The model comparison: run the chat test set against one model and score it.

Cases live in evals/chat_cases.yaml. Each runs against the same Bear Rocks run (built from cached Dolly Sods data,
so no OSM-derived file is committed) and says what must be true of the answer. Results go to evals/results/ (git-ignored).
"""

import json
import re
import time
from datetime import datetime, timezone
from pathlib import Path

import yaml

from backcountry.chat.models import ModelError
from backcountry.chat.service import chat_turn, start_names, trail_names
from backcountry.scoring import M_PER_MI

EVAL_REQUEST = {"trailhead": "bear_rocks", "total": "18-26", "nights": 2, "daily": "6-11", "max_gain_day": 2500}
EXPECT_KEYS = {"kind", "request", "request_contains", "lower", "day_shorter", "day_longer", "no_proposal", "grounded",
               "reply_includes_any", "proposal_or_note_includes", "mentions_hardest_day", "mentions_longest_day",
               "mentions_number"}


def load_cases(path: Path) -> list[dict]:
    cases = yaml.safe_load(path.read_text())
    for c in cases:
        if not {"id", "message", "expect"} <= set(c):
            raise ValueError(f"case {c.get('id')!r} needs id, message and expect")
        unknown = set(c["expect"]) - EXPECT_KEYS
        if unknown:
            raise ValueError(f"case {c['id']!r}: unknown expectation(s) {sorted(unknown)}")
    return cases


def _day_miles(request: dict, run: dict, n: int) -> list[float] | None:
    """Day lengths (miles) a proposal's camp pins would give, or None without a full set of pins."""
    pins = [float(x) for x in request.get("camps") or []]
    if not pins or len(pins) != (request.get("nights") or 0):
        return None
    bounds = [0.0, *pins, run["candidates"][n - 1]["length_m"] / M_PER_MI]
    return [b - a for a, b in zip(bounds, bounds[1:])]


def _mentions_day(reply: str, day: int) -> bool:
    return re.search(rf"\bday {day}\b", reply, re.IGNORECASE) is not None


def _mentions_number(reply: str, value: float) -> bool:
    for token in re.findall(r"\d[\d,]*(?:\.\d+)?", reply):
        decimals = len(token.split(".")[1]) if "." in token else 0
        if abs(float(token.replace(",", "")) - value) <= 0.5 * 10 ** -decimals + 1e-9:
            return True
    return False


def check_case(case: dict, result: dict | None, error: str | None, run: dict, n: int = 1) -> list[str]:
    if error:
        return [f"error: {error}"]
    e, problems = case["expect"], []
    c, current = run["candidates"][n - 1], run["request"]
    proposal = result.get("proposal")
    req = proposal["request"] if proposal else None
    reply = result.get("reply") or ""
    if "kind" in e and result["kind"] != e["kind"]:
        problems.append(f"kind is {result['kind']}, expected {e['kind']}")
    needs_proposal = any(k in e for k in ("request", "request_contains", "lower", "day_shorter", "day_longer")) or e.get("kind") == "change"
    if needs_proposal and "proposal_or_note_includes" not in e and req is None:
        problems.append("no proposal")
    if req is not None:
        for key, want in (e.get("request") or {}).items():
            got = req.get(key)
            same = ([float(x) for x in got] == [float(x) for x in want]) if isinstance(got, list) and isinstance(want, list) else got == want
            if not same:
                problems.append(f"{key} is {got}, expected {want}")
        for key, want in (e.get("request_contains") or {}).items():
            if want not in (req.get(key) or []):
                problems.append(f"{key} doesn't include {want}")
        if "lower" in e:
            key = e["lower"]
            before, after = current.get(key), req.get(key)
            if after is None or (before is not None and not after < before):
                problems.append(f"{key} did not go down ({before} → {after})")
        for key, sign in (("day_shorter", -1), ("day_longer", 1)):
            if key not in e:
                continue
            day = e[key]
            now = c["plan"]["days"][day - 1]["length_m"] / M_PER_MI
            miles = _day_miles(req, run, n)
            if miles is not None:
                ok = (miles[day - 1] - now) * sign > 0.05
            else:
                ok = sign < 0 and req["daily"] is not None and req["daily"][1] < now
            if not ok:
                problems.append(f"day {day} is not {'shorter' if sign < 0 else 'longer'}")
    if e.get("no_proposal") and req is not None:
        problems.append("made a proposal")
    if e.get("grounded") and result.get("withheld"):
        problems.append(f"reply was withheld ({result['withheld']})")
    if "reply_includes_any" in e and not any(w.lower() in reply.lower() for w in e["reply_includes_any"]):
        problems.append(f"reply has none of: {', '.join(e['reply_includes_any'])}")
    if "proposal_or_note_includes" in e:
        text = " ".join((proposal or {}).get("changes", [])) + " " + (result.get("note") or "") + " " + json.dumps(req or {})
        if e["proposal_or_note_includes"].lower() not in text.lower():
            problems.append(f"neither proposal nor note mentions {e['proposal_or_note_includes']}")
    days = (c.get("plan") or {}).get("days") or []
    if e.get("mentions_hardest_day") and days:
        hardest = max(days, key=lambda d: d["gain_ft"] or 0)["index"]
        if not _mentions_day(reply, hardest):
            problems.append(f"reply doesn't name day {hardest}")
    if e.get("mentions_longest_day") and days:
        longest = max(days, key=lambda d: d["length_m"])["index"]
        if not _mentions_day(reply, longest):
            problems.append(f"reply doesn't name day {longest}")
    if "mentions_number" in e:
        key = e["mentions_number"]
        value = c[key] / M_PER_MI if key.endswith("_m") else c[key]
        if not _mentions_number(reply, value):
            problems.append(f"reply doesn't give {key} ({value:.2f})")
    return problems


def run_eval(model, run: dict, cases: list[dict], trails: list[str], starts: list[dict], clock=time.monotonic) -> dict:
    rows = []
    for case in cases:
        t0 = clock()
        result = error = None
        try:
            result = chat_turn(model, run, 1, case["message"], case.get("history") or [], trails, starts)
        except ModelError as ex:
            error = str(ex)
        seconds = clock() - t0
        problems = check_case(case, result, error, run)
        rows.append({"id": case["id"], "ok": not problems, "problems": problems, "seconds": round(seconds, 2),
                     "kind": result and result["kind"], "reply": result and result["reply"],
                     "proposal": result and result["proposal"], "note": result and result["note"],
                     "withheld": result and result["withheld"], "error": error})
    summary = {"model": model.name, "cases": len(rows), "passed": sum(r["ok"] for r in rows),
               "errors": sum(r["error"] is not None for r in rows), "withheld": sum(bool(r["withheld"]) for r in rows),
               "mean_s": round(sum(r["seconds"] for r in rows) / max(len(rows), 1), 2)}
    return {"summary": summary, "cases": rows}


def summary_table(results: list[dict]) -> str:
    lines = [f"{'model':<28} {'passed':>8} {'errors':>7} {'withheld':>9} {'mean s':>7}"]
    for r in results:
        s = r["summary"]
        lines.append(f"{s['model']:<28} {s['passed']}/{s['cases']:<6} {s['errors']:>7} {s['withheld']:>9} {s['mean_s']:>7.1f}")
    return "\n".join(lines)


def default_run() -> tuple[dict, list[str], list[dict]]:
    """The eval's Bear Rocks run, planned from cached Dolly Sods data, with the region's names."""
    from backcountry.api.store import RegionStore, Settings
    from backcountry.planning import GenerateRequest, plan_trip
    from backcountry.serialize import run_payload

    loaded = RegionStore(Settings.default()).get("dolly_sods")
    result = plan_trip(loaded.region, loaded.raw, loaded.tg, GenerateRequest.from_dict(EVAL_REQUEST), dem=loaded.dem)
    now = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
    run = run_payload("eval", loaded.region, result, loaded.raw, loaded.tg, now, diff=None)
    return run, trail_names(loaded.tg), start_names(loaded.region)


def save_result(out: dict, results_dir: Path) -> Path:
    results_dir.mkdir(parents=True, exist_ok=True)
    stamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
    path = results_dir / f"{stamp}-{re.sub(r'[^A-Za-z0-9.]+', '_', out['summary']['model'])}.json"
    path.write_text(json.dumps(out, indent=1))
    return path
```

```python
@app.command(name="chat-eval")
def chat_eval(
    model: list[str] = typer.Option(..., "--model", help="ollama:<model>; repeat to compare several"),
    run: str = typer.Option(None, "--run", help="A saved run id under data/runs (default: plan the Bear Rocks eval run)"),
    cases: Path = typer.Option(REPO_ROOT / "evals" / "chat_cases.yaml", help="Test cases"),
):
    """Score chat models on the test set (local models are free; nothing is sent anywhere else)."""
    from backcountry.api.store import RegionStore, RunStore, Settings
    from backcountry.chat.eval import default_run, load_cases, run_eval, save_result, summary_table
    from backcountry.chat.models import model_from_spec, read_env
    from backcountry.chat.service import start_names, trail_names

    test_cases = load_cases(cases)
    if run:
        settings = Settings.default()
        the_run = RunStore(settings.runs_dir).load(run)
        loaded = RegionStore(settings).get(the_run["region"])
        trails, starts = trail_names(loaded.tg), start_names(loaded.region)
    else:
        the_run, trails, starts = default_run()
    env, results = read_env(), []
    for spec in model:
        m = model_from_spec(spec, env)
        typer.echo(f"{m.name}: {len(test_cases)} cases…")
        out = run_eval(m, the_run, test_cases, trails, starts)
        for row in out["cases"]:
            if not row["ok"]:
                typer.echo(f"  ✗ {row['id']}: {'; '.join(row['problems'])}")
        typer.echo(f"  saved {save_result(out, REPO_ROOT / 'evals' / 'results')}")
        results.append(out)
    typer.echo(summary_table(results))
```

```ts
import type { State } from "../store";
import type { ChatMessage } from "../types";
import { esc } from "./common";

function messageHtml(m: ChatMessage, i: number): string {
  if (m.role === "user") return `<div class="chat-msg chat-user">${esc(m.text)}</div>`;
  const parts = [m.text ? `<div>${esc(m.text)}</div>` : ""];
  if (m.withheld) parts.push(`<div class="note">(answer withheld: ${esc(m.withheld)})</div>`);
  if (m.note) parts.push(`<div class="note error">${esc(m.note)}</div>`);
  if (m.proposal) {
    const list = `<ul>${m.proposal.changes.map((c) => `<li>${esc(c)}</li>`).join("")}</ul>`;
    const foot = m.status === "ran" ? `<div class="note">Ran these settings.</div>`
      : m.status === "dismissed" ? `<div class="note">Dismissed.</div>`
      : `<div class="row"><button class="primary" data-run="${i}">Run</button><button class="link" data-dismiss="${i}">Dismiss</button></div>`;
    parts.push(`<div class="card proposal"><b>Proposed changes</b>${list}${foot}</div>`);
  }
  return `<div class="chat-msg chat-assistant">${parts.join("")}</div>`;
}

export function renderChat(s: State): string {
  if (!s.run) return "";
  const status = s.offline ? `<p class="note">Chat needs the server.</p>`
    : s.chatBusy ? `<p class="status">Thinking… (local model, can take ~20 s)</p>`
    : s.chatError ? `<p class="status error">${esc(s.chatError)}</p>` : "";
  const off = s.offline || s.chatBusy ? " disabled" : "";
  return `<section id="chat"><h2>Ask or change</h2>
<div id="chat-log">${s.chat.map(messageHtml).join("")}</div>
${status}
<div class="row"><input id="chat-input" name="chat" placeholder="e.g. make day 2 shorter, or: which day is hardest?" maxlength="1000"${off}><button class="primary" id="chat-send"${off}>Send</button></div>
<p class="note">Answers come only from this trip's data. Changes run only when you tap Run.</p></section>`;
}
```
