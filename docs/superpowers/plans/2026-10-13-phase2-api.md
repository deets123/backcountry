# Phase 2 piece 1: API over the engine — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the Phase 1 engine as a local HTTP API (regions, trailheads, trails, features, generate, saved runs, GPX/GeoJSON downloads) that the web app (piece 2) will call, with the CLI and API sharing one planning workflow.

**Architecture:** A `planning.py` module holds the generate workflow (`GenerateRequest` → `plan_trip`) that both `cli.py` and the API call. A `serialize.py` module turns engine objects into the JSON `Run`/`Candidate` shapes from the spec and builds GPX from stored pieces, so a download from a saved run is byte-identical to the CLI's file. The API lives in `src/backcountry/api/` (a subpackage of the one installed package, instead of the spec's separate `api/` folder: one install, one import root): `store.py` (region/graph cache, run files), `endpoints.py` (FastAPI routers), `app.py` (factory). `backcountry serve` runs it with uvicorn and serves `web/dist` when it exists.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, httpx (tests only), pytest; existing engine modules (`loops`, `split`, `features`, `route`, `export`, `ingest`, `region`).

**Spec:** `docs/superpowers/specs/2026-10-13-phase2-api-and-web-app-design.md`

## Global Constraints

- CLAUDE.md rules apply to every response: provenance (`data_sources` with retrieval dates), "unknown" for unverified facts, never the word "safe", miles/feet in user-facing text (the API returns engine units; `_m`/`_ft` suffixes name them).
- The API never produces geometry the engine didn't; it only serializes `Route`/`Candidate` objects.
- Errors: JSON `{"error": "<message>"}`; 400 for bad requests (message names the field and reuses CLI wording), 404 for unknown ids, 500 only for real failures.
- New dependencies must be explained in the commit message: `fastapi`, `uvicorn` (runtime), `httpx` (dev, for FastAPI's TestClient).
- Runs are stored as `data/runs/<run_id>.json`; `data/runs/` is gitignored (covered by the existing `data/` rules? No: add `data/runs/*` + `!data/runs/.gitkeep` to `.gitignore` in Task 5).
- The CLI's behavior and outputs must not change (existing tests stay green), except that error messages now come from `RequestError`.
- Tests run on the synthetic grid (`tests/conftest.py: build_grid`) with the raw cache written into a temp dir, as `tests/test_cli.py::_cache` does.

## Review Focus

1. A yaml trailhead whose node is no longer in the graph (data refreshed since the yaml was written): `/trailheads` must return it with `in_graph: false`, not crash. Test in Task 3.
2. Bad `generate` bodies: `total` with lo ≥ hi, `nights` without `daily`, `direction: "sideways"`, `type: "circle"`: each a 400 naming the field, never a 500. Tests in Task 1 (parsing) and Task 5 (HTTP).
3. Unknown run id, candidate index 0 or beyond the count, `?day=` beyond the plan: 404 with a message, never a stack trace. Tests in Task 6.
4. A region with OSM cached but no DEM: `generate` succeeds, `gain_ft` is null, notes say "elevation unknown". Test in Task 5.
5. Two requests for the same region must not rebuild the graph twice; a region without a cache must return a 404 that names `backcountry ingest`. Tests in Task 3.

# src/backcountry/planning.py
"""The generate workflow, shared by the CLI and the API.

GenerateRequest validates the user's settings; plan_trip resolves the start, runs the
loop search, and attaches elevation, day plans and along-route features to every
candidate. Both callers then only format and store the result.
"""

from dataclasses import dataclass, field

from backcountry import ingest
from backcountry.elevation import densify
from backcountry.features import along_route
from backcountry.loops import avoided_keys, search
from backcountry.route import add_elevation, resolve_point
from backcountry.scoring import M_PER_MI, Weights
from backcountry.split import resolve_pins, split_route

KINDS = {"loop": ("loop",), "lollipop": ("lollipop",), "any": ("loop", "lollipop")}


class RequestError(ValueError):
    """A bad setting; `field` names it and the message reuses the CLI wording."""

    def __init__(self, field: str, message: str):
        super().__init__(message)
        self.field = field


def parse_range(value, field: str) -> tuple[float, float]:
    """'18-26' or [18, 26] -> (18.0, 26.0), with 0 < lo < hi."""
    try:
        if isinstance(value, str):
            lo, hi = (float(x) for x in value.split("-"))
        else:
            lo, hi = (float(x) for x in value)
        if not 0 < lo < hi:
            raise ValueError
    except (ValueError, TypeError):
        raise RequestError(field, f"{field} must look like 18-26 (miles, low-high); got {value!r}")
    return lo, hi


@dataclass
class GenerateRequest:
    trailhead: str
    total: tuple[float, float]
    nights: int | None = None
    daily: tuple[float, float] | None = None
    max_gain_day: float | None = None
    type: str = "any"
    count: int = 3
    no_roads: bool = False
    road_weight: float = 1.0
    repeat_weight: float = 0.5
    camps: list[str] = field(default_factory=list)
    camps_at_sites: bool = False
    must_visit: list[str] = field(default_factory=list)
    avoid: list[str] = field(default_factory=list)
    direction: str | None = None

    @classmethod
    def from_dict(cls, data: dict) -> "GenerateRequest":
        if not data.get("trailhead"):
            raise RequestError("trailhead", "trailhead is required: a trailhead id, an OSM node id, or lat,lon")
        total = parse_range(data.get("total"), "total")
        nights = data.get("nights")
        if nights is not None and (not isinstance(nights, int) or nights < 1):
            raise RequestError("nights", "nights must be a whole number of at least 1")
        daily = parse_range(data["daily"], "daily") if data.get("daily") is not None else None
        if nights is not None and daily is None:
            raise RequestError("daily", "nights needs daily (e.g. 6-11)")
        type_ = data.get("type") or "any"
        if type_ not in KINDS:
            raise RequestError("type", "type must be loop, lollipop, or any")
        direction = data.get("direction") or None
        if direction not in (None, "cw", "ccw"):
            raise RequestError("direction", "direction must be cw or ccw")
        count = data.get("count", 3)
        if not isinstance(count, int) or count < 1:
            raise RequestError("count", "count must be a whole number of at least 1")
        return cls(
            trailhead=str(data["trailhead"]), total=total, nights=nights, daily=daily,
            max_gain_day=data.get("max_gain_day"), type=type_, count=count,
            no_roads=bool(data.get("no_roads", False)), road_weight=float(data.get("road_weight", 1.0)),
            repeat_weight=float(data.get("repeat_weight", 0.5)), camps=[str(c) for c in data.get("camps") or []],
            camps_at_sites=bool(data.get("camps_at_sites", False)),
            must_visit=[str(m) for m in data.get("must_visit") or []], avoid=[str(a) for a in data.get("avoid") or []],
            direction=direction,
        )

    def to_dict(self) -> dict:
        return {
            "trailhead": self.trailhead, "total": list(self.total), "nights": self.nights,
            "daily": list(self.daily) if self.daily else None, "max_gain_day": self.max_gain_day, "type": self.type,
            "count": self.count, "no_roads": self.no_roads, "road_weight": self.road_weight,
            "repeat_weight": self.repeat_weight, "camps": list(self.camps), "camps_at_sites": self.camps_at_sites,
            "must_visit": list(self.must_visit), "avoid": list(self.avoid), "direction": self.direction,
        }

    @property
    def kinds(self) -> tuple:
        return KINDS[self.type]

    @property
    def total_m(self) -> tuple[float, float]:
        return self.total[0] * M_PER_MI, self.total[1] * M_PER_MI

    @property
    def daily_m(self) -> tuple[float, float] | None:
        return (self.daily[0] * M_PER_MI, self.daily[1] * M_PER_MI) if self.daily else None


@dataclass
class PlanResult:
    report: dict
    start: dict
    request: GenerateRequest


def must_spec(tg, region, text: str) -> dict:
    """A must-visit value: a point (trailhead id, node id, lat,lon) or a trail name."""
    try:
        return {"node": resolve_point(tg, region, text)["node"]}
    except ValueError as point_err:
        if any((d["name"] or "").lower() == text.lower() for *_, d in tg.graph.edges(data=True)):
            return {"name": text}
        raise RequestError("must_visit", f"must_visit {text!r}: not a trail name here, and {point_err}")


def usfs_campgrounds(region) -> list[dict]:
    usfs = ingest.load_usfs(region) if region.usfs_crosscheck else None
    feats = (usfs or {"layers": {}})["layers"].get("rec_sites", {}).get("geojson", {}).get("features", [])
    return [{"source": f"usfs:site/{f['properties'].get('site_id')}", "subtype": f["properties"].get("site_subtype"),
             "name": f["properties"].get("public_site_name") or f["properties"].get("site_name"),
             "lat": f["geometry"]["coordinates"][1], "lon": f["geometry"]["coordinates"][0]}
            for f in feats if f["properties"].get("site_subtype") == "CAMPGROUND"]


def plan_trip(region, raw, tg, req: GenerateRequest) -> PlanResult:
    try:
        start = resolve_point(tg, region, req.trailhead)
    except ValueError as e:
        raise RequestError("trailhead", str(e))
    musts = [must_spec(tg, region, m) for m in req.must_visit]
    if req.avoid:
        try:
            avoided_keys(tg, req.avoid)
        except ValueError as e:
            raise RequestError("avoid", str(e))
    weights = Weights(road=req.road_weight, repeat=req.repeat_weight)
    dem = ingest.load_dem(region)
    sites = ingest.camp_sites(raw)
    water = ingest.water_features(raw)
    campgrounds = usfs_campgrounds(region)

    def elevate(c):
        if dem is not None:
            add_elevation(c.route, dem, tg.crs)
        else:
            d, _ = densify(c.route.line_utm)  # distance-only profile so days can still be split
            c.route.profile = {"d_m": d, "z_m": [None] * len(d)}
            c.route.notes.append("elevation unknown: no DEM cached (run `backcountry dem`)")

    def evaluate(c):
        elevate(c)
        pins, problems = resolve_pins(c.route, req.camps, sites)
        lo, hi = req.daily_m
        c.plan = split_route(c.route, req.nights, lo, hi, req.max_gain_day, weights, sites, pins_m=pins,
                             sites_only=req.camps_at_sites)
        for p in problems:
            c.plan.notes.append(f"Pinned {p}")
            c.plan.ok = False
        c.features = along_route(c.route, sites, water, campgrounds, c.plan)
        return c.plan.penalty + 100.0 * len(problems)

    lo, hi = req.total_m
    report = search(tg, start["node"], lo, hi, kinds=req.kinds, count=req.count, no_roads=req.no_roads,
                    weights=weights, evaluate=evaluate if req.nights is not None else None,
                    avoid=req.avoid, must_visit=musts, direction=req.direction)
    if req.nights is None:
        for c in report["candidates"]:
            elevate(c)
            c.features = along_route(c.route, sites, water, campgrounds)
    return PlanResult(report=report, start=start, request=req)
```

# src/backcountry/serialize.py
"""JSON shapes for the API (Run, Candidate) and GPX built from those shapes.

A GPX built from a stored run is byte-identical to the CLI's route.gpx for the same
request because write_route uses the same builders.
"""

from dataclasses import asdict

from shapely.geometry import mapping

from backcountry.export import candidate_record, route_pieces, route_segments, route_waypoints
from backcountry.ingest import DEM_ATTRIBUTION, OSM_ATTRIBUTION

KNOWN_GAPS = [
    "water: map features only; whether water is present, flowing, or drinkable is unknown",
    "campsites: map features only; existence, status, and legality are unknown",
    "permits: not checked",
    "closures: not checked",
    "trail conditions: not checked",
    "trailhead access: not checked",
]


def gpx_description(route, osm_retrieved_at: str) -> str:
    sources = ", ".join(dict.fromkeys(e["source"] for e in route.edges))
    text = f"Trail data {OSM_ATTRIBUTION}, retrieved {osm_retrieved_at}. Geometry is exact OSM vertices from {sources}."
    if route.elevation_source:
        src = route.elevation_source
        text += f" Elevations from {src.get('dataset', 'DEM')} ({src.get('attribution', '')})."
    else:
        text += " No elevations."
    return text


def _gpx_doc(name: str, description: str):
    import gpxpy.gpx

    g = gpxpy.gpx.GPX()
    g.creator = "backcountry route engine"
    g.name, g.description = name, description
    return g


def _track(piece: dict):
    import gpxpy.gpx

    track = gpxpy.gpx.GPXTrack(name=piece["name"])
    track.segments.append(gpxpy.gpx.GPXTrackSegment(
        [gpxpy.gpx.GPXTrackPoint(lat, lon, elevation=ele) for lon, lat, ele in piece["points"]]))
    return track


def _waypoint(w: dict):
    import gpxpy.gpx

    return gpxpy.gpx.GPXWaypoint(w["lat"], w["lon"], elevation=w["ele"], name=w["name"], description=w["desc"])


def build_gpx(title: str, description: str, pieces: list[dict], waypoints: list[dict]) -> str:
    g = _gpx_doc(title, description)
    g.tracks += [_track(p) for p in pieces]
    g.waypoints += [_waypoint(w) for w in waypoints]
    return g.to_xml()


def day_gpx(title: str, description: str, piece: dict, waypoints: list[dict]) -> str:
    g = _gpx_doc(f"{title}, {piece['name']}", description)
    g.tracks.append(_track(piece))
    g.waypoints += [_waypoint(w) for w in waypoints if piece["start_m"] - 1 <= w["dist_m"] <= piece["end_m"] + 1]
    return g.to_xml()


def camp_payload(camp) -> dict:
    return asdict(camp)


def plan_payload(plan) -> dict | None:
    if plan is None:
        return None
    return {
        "nights": plan.nights, "daily_min_m": plan.daily_min_m, "daily_max_m": plan.daily_max_m,
        "max_gain_ft": plan.max_gain_ft, "days": [asdict(d) for d in plan.days],
        "camps": [camp_payload(c) for c in plan.camps], "ok": plan.ok, "violations": list(plan.violations),
        "notes": list(plan.notes), "penalty": plan.penalty,
    }


def candidate_payload(i: int, c, start_text: str, osm_retrieved_at: str) -> dict:
    title = f"{start_text} to {start_text} (loop)"
    pieces = route_pieces(c.route, c.plan)
    for p in pieces:
        p["points"] = [list(pt) for pt in p["points"]]
    return {
        "index": i, "kind": c.kind, "length_m": c.length_m, "gain_ft": c.route.gain_ft, "loss_ft": c.route.loss_ft,
        "road_m": c.road_m, "last_resort_m": c.last_resort_m, "repeated_m": c.repeated_m, "penalty": c.penalty,
        "segments": route_segments(c.route),
        "geometry": mapping(c.route.line_wgs84),
        "pieces": pieces,
        "waypoints": route_waypoints(c.route, start_text, f"{start_text} (loop)", c.plan),
        "plan": plan_payload(c.plan),
        "features": c.features or [],
        "profile": c.route.profile,
        "title": title,
        "description": gpx_description(c.route, osm_retrieved_at),
        "notes": list(c.route.notes),
        "record": candidate_record(i, c),
    }


def data_sources(region, raw, tg) -> list[dict]:
    out = [{"name": "OpenStreetMap via Overpass API", "retrieved_at": raw["retrieved_at"], "attribution": OSM_ATTRIBUTION}]
    src = tg.graph.graph.get("elevation_source")
    if src:
        out.append({"name": src.get("dataset", "DEM"), "retrieved_at": src.get("retrieved_at"), "attribution": DEM_ATTRIBUTION})
    return out


def run_payload(run_id: str, region, result, raw, tg, generated_at: str, diff: str | None) -> dict:
    report = result.report
    return {
        "run_id": run_id, "region": region.id, "request": result.request.to_dict(), "generated_at": generated_at,
        "start": result.start,
        "search": {k: v for k, v in report.items() if k != "candidates"},
        "candidates": [candidate_payload(i, c, result.start["how"], tg.retrieved_at)
                       for i, c in enumerate(report["candidates"], 1)],
        "data_sources": data_sources(region, raw, tg),
        "known_gaps": KNOWN_GAPS,
        "diff": diff,
    }

# src/backcountry/api/store.py
"""Loaded regions (graph built once per process) and saved runs."""

import json
import random
from dataclasses import dataclass, field
from datetime import datetime, timezone
from pathlib import Path

from backcountry import ingest
from backcountry.graph import build_graph, qa_summary
from backcountry.region import REGIONS_DIR, REPO_ROOT, load_region


@dataclass
class Settings:
    raw_dir: Path | None = None
    runs_dir: Path | None = None
    regions_dir: Path | None = None

    @classmethod
    def default(cls) -> "Settings":
        return cls(raw_dir=ingest.RAW_DIR, runs_dir=REPO_ROOT / "data" / "runs", regions_dir=REGIONS_DIR)


@dataclass
class LoadedRegion:
    region: object
    raw: dict
    tg: object
    summary: dict
    dem: object = None
    builds = 0  # class-level counter, for tests

    @property
    def node_component(self) -> dict:
        return self.summary["node_component"]


class RegionStore:
    def __init__(self, settings: Settings):
        self.settings = settings
        self._loaded: dict[str, LoadedRegion] = {}

    def ids(self) -> list[str]:
        return sorted(p.stem for p in (self.settings.regions_dir or REGIONS_DIR).glob("*.yaml"))

    def summaries(self) -> list[dict]:
        out = []
        for rid in self.ids():
            region = load_region(rid, self.settings.regions_dir)
            cache = ingest.latest_cache(region, self.settings.raw_dir)
            raw_meta = json.loads(cache.read_text())["retrieved_at"] if cache else None
            out.append({
                "id": region.id, "name": region.name, "crs": region.crs, "bbox": vars(region.bbox),
                "osm_retrieved_at": raw_meta,
                "dem": ingest.latest_cache(region, self.settings.raw_dir, prefix="dem13") is not None,
                "usfs": ingest.latest_cache(region, self.settings.raw_dir, prefix="usfs") is not None,
                "trailheads": len(region.trailheads),
            })
        return out

    def get(self, region_id: str) -> LoadedRegion:
        if region_id in self._loaded:
            return self._loaded[region_id]
        if region_id not in self.ids():
            raise KeyError(f"No region {region_id!r}")
        region = load_region(region_id, self.settings.regions_dir)
        raw = ingest.load_raw(region, self.settings.raw_dir)  # FileNotFoundError names `backcountry ingest`
        tg = build_graph(raw, region.crs)
        loaded = LoadedRegion(region=region, raw=raw, tg=tg, summary=qa_summary(tg),
                              dem=ingest.load_dem(region, raw_dir=self.settings.raw_dir))
        LoadedRegion.builds += 1
        self._loaded[region_id] = loaded
        return loaded


class RunStore:
    def __init__(self, runs_dir: Path):
        self.runs_dir = runs_dir

    def new_id(self) -> str:
        stamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
        return f"{stamp}-{random.randrange(16**4):04x}"

    def save(self, run: dict) -> Path:
        self.runs_dir.mkdir(parents=True, exist_ok=True)
        path = self.runs_dir / f"{run['run_id']}.json"
        path.write_text(json.dumps(run))
        return path

    def load(self, run_id: str) -> dict:
        path = self.runs_dir / f"{run_id}.json"
        if not path.exists() or "/" in run_id or ".." in run_id:
            raise KeyError(f"No run {run_id!r}")
        return json.loads(path.read_text())

    def latest(self, region_id: str, trailhead: str) -> dict | None:
        """The most recent saved run for this region + trailhead (for the diff)."""
        for path in sorted(self.runs_dir.glob("*.json"), reverse=True) if self.runs_dir.exists() else []:
            run = json.loads(path.read_text())
            if run["region"] == region_id and run["request"]["trailhead"] == trailhead:
                return run
        return None
```

from fastapi import FastAPI, Request

from backcountry.api.endpoints import router

def create_app(settings: Settings | None = None) -> FastAPI:
    settings = settings or Settings.default()
    app = FastAPI(title="Backcountry route engine", version="0.2")
    app.state.settings = settings
    app.state.regions = RegionStore(settings)
    app.state.runs = RunStore(settings.runs_dir) if settings.runs_dir else None
    app.include_router(router)

    @app.exception_handler(RequestError)
    def bad_request(request: Request, exc: RequestError):
        return JSONResponse(status_code=400, content={"error": str(exc), "field": exc.field})

    @app.exception_handler(KeyError)
    def not_found(request: Request, exc: KeyError):
        return JSONResponse(status_code=404, content={"error": exc.args[0] if exc.args else "not found"})

    @app.exception_handler(FileNotFoundError)
    def not_cached(request: Request, exc: FileNotFoundError):
        return JSONResponse(status_code=404, content={"error": str(exc)})

    return app

    try:

from fastapi.responses import Response

from backcountry.serialize import build_gpx, day_gpx


def _candidate(request: Request, run_id: str, n: int) -> tuple[dict, dict]:
    run = request.app.state.runs.load(run_id)
    if not 1 <= n <= len(run["candidates"]):
        raise KeyError(f"Run {run_id} has {len(run['candidates'])} candidates; there is no candidate {n}")
    return run, run["candidates"][n - 1]


@router.get("/runs/{run_id}/candidates/{n}.gpx")
def candidate_gpx(run_id: str, n: int, request: Request, day: int | None = None):
    run, c = _candidate(request, run_id, n)
    pieces = [{**p, "points": [tuple(pt) for pt in p["points"]]} for p in c["pieces"]]
    if day is None:
        text, name = build_gpx(c["title"], c["description"], pieces, c["waypoints"]), f"{run_id}_candidate_{n}.gpx"
    else:
        piece = next((p for p in pieces if p["day"] == day), None)
        if piece is None:
            raise KeyError(f"Candidate {n} has no day {day}")
        text, name = day_gpx(c["title"], c["description"], piece, c["waypoints"]), f"{run_id}_candidate_{n}_day_{day}.gpx"
    return Response(content=text, media_type="application/gpx+xml",
                    headers={"Content-Disposition": f'attachment; filename="{name}"'})


@router.get("/runs/{run_id}/candidates/{n}.geojson")
def candidate_geojson(run_id: str, n: int, request: Request):
    run, c = _candidate(request, run_id, n)
    feats = [{"type": "Feature", "geometry": {"type": "LineString", "coordinates": [[lon, lat] for lon, lat, _ in p["points"]]},
              "properties": {"name": p["name"].split(":")[0], "day": p["day"], "length_m": p["length_m"],
                             "gain_ft": p["gain_ft"], "loss_ft": p["loss_ft"]}} for p in c["pieces"]]
    feats += [{"type": "Feature", "geometry": {"type": "Point", "coordinates": [w["lon"], w["lat"]]},
               "properties": {"name": w["name"], "kind": w["kind"], "description": w["desc"], "dist_m": w["dist_m"]}}
              for w in c["waypoints"]]
    return {"type": "FeatureCollection", "attribution": run["data_sources"][0]["attribution"], "features": feats}
